# Auto-downgrade Mode Fallback + rename disclosure field

**Status:** done

## What to build

Implement the Mode Fallback policy decided in **ADR-0001** (`octora-api/docs/adr/0001-mode-fallback-is-auto-downgrade-with-post-hoc-disclosure.md`):

- When a Position in `fast-private` cannot complete its private path within `fundingTtlMinutes` (Anonymity Set Guard never clears, mixer withdraw fails after pre-funding, etc.), the backend **auto-downgrades** to `standard` without gating on user ACK
- The downgrade emits an Activity Record carrying Recovery Guidance flagged for disclosure
- The frontend renders a post-hoc banner / Activity Record entry explaining: "Octora downgraded this Position to standard mode to keep the trade window open. Your origin wallet is now linked to this Position."
- Global policy — no per-Position toggle. Users who want strict consent-before-downgrade pick `standard` upfront.
