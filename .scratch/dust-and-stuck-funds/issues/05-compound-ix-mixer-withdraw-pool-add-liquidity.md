# Atomic compound ix: mixer.withdraw → pool.add_liquidity

**Status:** ready-for-agent
**Type:** enhancement
**Slice:** AFK

## What to build

A single CPI-chained on-chain instruction that withdraws a denomination from a **Mixer Pool** and adds liquidity to a Meteora DLMM pool in one transaction — eliminating the Stealth Wallet's intermediate balance and the dust trail that comes with it.

```
mixer.withdraw -> pool.add_liquidity
       \-> position NFT owner = stealth
       \-> sub-denom dust never lands in stealth account
```

- Withdraw lamports → pool position in one ix batch
- Relayer fee is deducted from the denomination *inside* the CPI
- No transient "stealth holds 4.97 SOL" state observable on-chain
- A bot watching the chain sees: relayer signs, denom in, position out. No dust trail between the two.

This is the **Position Open** (flow 2) on-chain primitive. It is distinct from the user-signed atomic deposit+addLP in issue 02 — that one removes the user-side stuck state; this one removes the bot-observable dust state. Both can ship; both produce different privacy guarantees.

Note: per the existing `.out-of-scope/sweeper.md` rejection, this is the canonical fix that obsoletes the dust sweeper. Issue 08 cleans up sweeper references after this lands.
